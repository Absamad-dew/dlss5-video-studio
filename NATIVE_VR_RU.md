# Studio Native VR — 5 сентября 2026

Новый путь работает **в нашей вкладке VR**, с методом **RowFlow V3**.
Отдельные вкладка, обработчик, настройки и веса IW3 не изменяются.
Это реализация основной части аудита, а не обещание законченного ускорения
всего проекта или полного совпадения любого результата с IW3.

## Быстрый старт

1. VR → Depth 3D → RowFlow V3 → Native.
2. «Подготовка геометрии»: IW3-совместимая. Для наших gamma / motion /
   foreground / background выберите Studio. Неактивные параметры отключаются.
3. DA3 Mono, вход 518 — исходная точка. 644/812 увеличивает затраты и детализацию
   глубины, **не** размер RGB. Можно выбрать DA3 Small / Base / Large 1.1 / Giant 1.1.
   Модель без установленных весов не подменяется: программа выдаёт ошибку до
   обработки. Large/Giant имеют некоммерческую лицензию.
4. Для скорости и сравнения с обычным RowFlow сначала отключите восстановление.
   Source Atlas переносит только проверенные реальные пиксели. Temporal Video
   дополнительно запускает видеомодель на оставшихся областях.
5. Full-SBS сохраняет оба глаза целиком: 3840×2160 на глаз → 7680×2160 файл.
   Half-SBS сжимает глаза только после стереосинтеза и восстановления.
6. «Передача DLSS → VR»: Авто использует локальный RGB-поток без промежуточного
   сжатия для совместимых заданий. Последовательно — резервный вариант.

## Ускорение V2

- Atlas GPU обрабатывает только пиксели маски; карты разворачиваются один раз
  на глаз. Проверка цвета общая для обоих глаз. Пороги принятия не ослаблены.
- ORB вычисляется один раз на кадр; обе стороны DIS-пары сохраняются и
  используются повторно. Один CPU-поток готовит регистрации параллельно CUDA.
- Оригинальные RGB-доноры имеют ограниченный GPU-кэш 384 MiB. В 4K это не
  хранение фильма в VRAM; вытеснение не меняет пиксели и не уменьшает разрешение.
- В совместимом DualDPT DA3 не считается независимая ветка ray, не используемая
  нашим depth-потребителем. При первом вызове результат depth/confidence
  сравнивается побитово с исходной головой. При несовпадении остаётся исходное
  исполнение. Sky-ветка DA3 Mono не удаляется. Веса, AMP и depth-resolution прежние.
- Потоковый режим позволяет перекрывать подготовку, DLSS и VR. Видеокодирование
  выполняется только на выходе; промежуточные HEVC/YUV-потери исключены.
  Это ещё не zero-copy: остаются GPU readback, RGB pipe и загрузка в CUDA.
- Каждый кадр обрабатывается ровно один раз. Очередь VR — максимум 18 кадров;
  RGB/guide/depth-чанки освобождаются после потребления. Память не зависит от
  полной длительности фильма. Рабочий лимит depth-кэша 8 GiB сохраняется.
- Прогресс потока показывает готовые стереокадры, подготовленные кадры и очередь.
  Исчезновение контроллера, EOF и отсутствие прогресса завершаются ошибкой,
  а не успешным неполным файлом; отмена завершает только процессы этого задания.
- Studio motion-depth корректно работает при разных разрешениях canonical
  depth и motion-guide: уменьшается/увеличивается только поле движения, а не
  карта глубины. Масштаб векторов берётся из исходного motion-заголовка.

Авто сейчас применимо к Native RowFlow, Off/SourceAtlas/TemporalVideo,
обычному DLSS перед стерео и моделям Selected/Mono/Small/Base. Для Large/Giant,
внешнего апскейлера, per-eye DLSS, live-preview, сравнения или сохранения
временных файлов используется последовательный путь. В журнале ищите
`VR_SCHEDULING`, в отчёте — `vr_streaming`. При нехватке VRAM выберите
«Последовательно»: одновременная загрузка моделей требует больше памяти.
Новый GPU Atlas работает и в последовательном Native-режиме.

Нельзя сравнивать потоковый и прежний финальный RGB на побитовое равенство:
раньше перед VR было дополнительное сжатие, теперь его нет. Эквивалентность
самого Atlas проверяется отдельно, на одинаковом входном RGB и depth.

## Что изменилось

`Видео → одна нейронная depth → [DLSS-guide / сырая float32 disparity]`

`DLSS RGB + raw disparity → RowFlow → реальные доноры → остаточная видеосеть → NVENC`

- NGX получает свою уменьшенную и сглаженную текстуру. VR читает отдельные
  `.vrd`, **до** guide gamma, clipping и motion-фильтра. Это один inference,
  а не две разные модели. В Native depth вычисляется для каждого кадра.
- Depth-дистанция преобразуется в disparity (больше = ближе). Для DA3 Mono
  сохранена обработка неба. Знак edge dilation исправлен в новом пути.
- RowFlow использует исходные веса, flips, auto-steps и последовательные RGB
  выборки. Оба глаза считаются одним батчем. Запоминается реальная карта варпа.
- Маска восстановления требует одновременно отсутствия геометрического
  покрытия и несогласованного владельца пикселя в карте RowFlow. Одной
  приблизительной маски z-splat недостаточно для перекраски силуэта.
- Доноры ищутся в исходных, а не уже деформированных глазных координатах.
  Сначала регистрируется фон; при непригодности одной гомографии используется
  двунаправленный DIS. Движение берётся с наблюдаемого фонового края, а не с
  закрывающего его человека. Проверяются bounds, depth, цвет и roundtrip.
- Берутся кадры ±3 в пределах одной сцены. При смене сцены история и GPU-кэш
  сбрасываются. Это небольшой локальный atlas, пока не дальний keyframe-bank.
- Остаток обрабатывает исходная Light Video Inpaint из установленного IW3:
  12 контекстных кадров, 6 публикуемых, контекст 3+3. Не MI-GAN и не diffusion
  всего изображения. Модель не загружается при выключенном neural-fill.
- Нативные кропы имеют общую фазу сетки, halo 192/256 и неперекрывающееся
  владение выходом. Соседние области объединяются до добавления halo.
  Вне маски RGB не меняется. Это не гарантия побитового равенства полнокадровой
  сети: на границах и больших областях нужны дополнительные проверки.
- Кэшируются только признаки **до** временного смешивания: ключи включают
  сцену, глаз, кадр и координаты кропа. Выходы контекстных кадров не декодируются
  без необходимости. GPU-кэш ограничивается выбранным числом МБ.
- Очередь ограничена 18 кадрами CPU uint8. Признаки не растут с длиной фильма.
  Для чтения/записи используются закреплённые буферы; выборка фонового RGB
  переводит в float только запрошенные пиксели, не весь 4K кадр.
- Между стереосинтезом, atlas и видеосетью нет FFV1-масок, промежуточного
  стереофайла и повторного кодирования. Финальный VR encode один. Предварительный
  DLSS и необязательные DLSS-проходы по глазам пока остаются отдельными стадиями.
- Для дополнительных DLSS-проходов по глазам экспортируется проецированная
  depth и применяется replay вместо повторного запуска depth-модели.
- Публикация ведёт точный счёт кадров; аудио остаётся на исходной временной
  шкале существующего mux. Не следует считать это новым решением старых
  realtime audio-проблем: realtime этим обновлением не изменялся.

## Настройки и цена качества

| Настройка | Эффект |
|---|---|
| Native / Legacy | Новый RowFlow-путь / прежний путь для сравнений и старых генеративных моделей |
| IW3-совместимая / Studio | Без художественной коррекции / дополнительные gamma, motion, кривые и силы планов |
| Depth 392/518/644/812 | Разрешение входа DA3, не скрытая настройка уменьшения RGB |
| Eager / CUDA Graph | Обычный запуск / экспериментальный граф с проверкой захвата и первых трёх replay; при отличии возвращается eager |
| Feature cache 0–1024 МБ | Память GPU против повторного вычисления пространственных признаков |
| Halo 192/256 | Контекст видеосети вокруг ROI; больше — тяжелее |
| Сила заполнения | Смешивание только в остаточной маске; не сила обработки всего кадра |
| Опорный глаз | Симметрично либо один глаз сохраняет исходную геометрию |

## Проверки и ограничения

Все вычислительные проверки выполняются на ноутбуке RTX 4060 через CoreBroker.
На ПК RTX 5080 допускается только передача файлов без запуска тестов.
Локальные отчёты: `qa-output/native-vr/`; скрипты воспроизведения —
`tests/qa_native_vr.py`, `tests/test_vr_native.py`.

- Проверены короткие 1440p и UHD-видео; очередь выдаёт каждый кадр ровно один
  раз, включая короткие клипы и разрывы сцен. Проверены все варианты опорного
  глаза, несколько шагов RowFlow и одинаковость результата с/без feature cache.
- На первом 1440p QA-проходе исправление CPU-подготовки масок сократило
  21,15 с до 7,81 с для 18 кадров. Все 18 декодированных кадров совпали.
  Это короткий замер отдельного стерео/fill этапа, не скорость всей программы
  и не универсальная гарантия ускорения в 2,7 раза.
- DA3 Mono 518 в коротком тесте: примерно 0,29 с/кадр после прогрева;
  CUDA Graph после проверки replay — около 0,275 с. Граф здесь даёт небольшой
  выигрыш, не кратное ускорение; первые кадры дороже из-за проверки.
- Тяжёлое заполнение UHD по-прежнему может быть медленным. В сценах с тонкими
  проводами, частыми краями и широко разбросанными дырками площадь кропов
  велика. По умолчанию не уменьшать RGB, depth-вход и частоту inference ради
  красивого числа FPS. Для обычного RowFlow восстановление можно отключить.
- Доноры не создают невидимую в источнике информацию. Если фон не показан
  ни в одном соседнем кадре, остаётся нейросеть. Перенос намеренно консервативен.
- В последовательном пути raw depth записывается на диск до VR-стадии и имеет лимит 8 ГиБ. После
  первого предсказания проверяется размер всего выбранного диапазона, чтобы
  не дойти до лимита только после длительного расчёта. Ошибка сообщает
  допустимое число кадров. Длинные фильмы пока разбивайте на части.
  Потоковый путь освобождает чанки по мере чтения. Дальние keyframes и общий
  GPU decode/encode без RGB-pipe **ещё не реализованы**.
- Строгого общего доказательства «не хуже IW3» по произвольным сценам нет.
  Оставлен Legacy и неизменённый отдельный IW3 для контролируемых сравнений.
  Не завершён также большой 2K/4K визуальный набор и длительный аудиотест.

## Обновление и откат

`scripts/Deploy-NativeVrUpdate.ps1 -TargetRoot <папка Studio>` копирует только
небольшие изменённые файлы, сохраняет предыдущие версии в
`temp/native-vr-backup-*`, проверяет SHA-256 и неизменность шести файлов IW3.
Веса, runtime, пользовательские пресеты и видео не копируются и не удаляются.
При ошибке копирования восстанавливаются прежние версии. Для ручного отката
верните файлы из указанной backup-папки по тем же относительным путям.
После обновления перезапустите окно Studio; активные обработки не прерываются.
