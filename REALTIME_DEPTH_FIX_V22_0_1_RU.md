# Исправление запуска Medium / Maximum — 22.0.1

## Причина

Логи с DESKTOP-Q2BI3N8 от 04.09.2026, 15:17–15:18: в обоих профилях
выбрана `VideoDepthSmall`. Runner прерывался до инициализации GPU из-за
отсутствия `models/depth/video_depth_anything_vits.pth`. Каталог
`third_party/video-depth-anything` на ПК содержал только пустые подпапки.
На ноутбуке также отсутствовали веса и реализация. Это ошибка комплектации,
а не свидетельство недостаточной производительности RTX 5080.

Установщик одной модели тоже был неисправен: PowerShell разворачивал строку
`video-small` через splatting в отдельные символы. Исправлено на `string[]`.

## Изменения

- Video Depth Anything Small устанавливается вместе с потоковой реализацией.
  Веса: revision `256875362cff76724b920335dfb4b29dd611f66e`, 116440756 байт,
  SHA-256 `13379300b739e659f076a59d52e9801bd8d38c541a7e71f73bbca4dcfb013609`.
  Код: commit `4f5ae23172ba60fd7bc11ef671cca678842c7072`, только 21 файл
  Python/лицензии/README (126636 байт), без демонстрационных видео.
  Источники: [официальные веса](https://huggingface.co/depth-anything/Video-Depth-Anything-Small),
  [официальный код](https://github.com/DepthAnything/Video-Depth-Anything).
- `INSTALL_VIDEO_DEPTH.cmd` восстанавливает этот комплект отдельно.
  SHA-256 весов и архива исходников проверяются; существующий изменённый код
  установщик не перезаписывает молча. Корень больше не привязан к старой V11.
- Общая проверка модели в UI, realtime-player и process-video выполняется
  до URL-resolver, звука и GPU. Неполные модели отмечены в списке.
  Автоматической подмены Video Depth на более лёгкую модель нет.
- Сборщик portable и основного model pack теперь включают Video Depth и код.
- При локальном тесте дополнительно воспроизведён crash `0xc0000409` в
  `nvngx_dlssg.dll` **после** успешного вывода всех кадров. Добавлены остановка
  FG, ожидание очередей GPU и `slShutdown()` до освобождения ресурсов.
  Это соответствует lifecycle в bundled Streamline ProgrammingGuideDLSS_G.
  Ошибка host теперь содержит его exit code.

## Проверки — только ноутбук RTX 4060

CoreBroker: 8 физических / 16 логических CPU, один L3, без эксклюзивного
резервирования, блокировки GPU и дисков. Сборка native — 4 физических CPU.

| Проверка | Результат |
|---|---|
| Отсутствующие/пустые веса и код, ранний отказ Medium/Maximum | 17 проверок пройдены; звук/сеть не запускаются |
| Установка VideoSmall | Успешна, вес и код проверены по SHA-256 |
| Medium, 1080p, 150 исходных кадров, VideoDepth + RAFT + DLSS-G x2 | exit 0, 149 сгенерированных кадров, 49.96 FPS вывода, 0 underrun |
| Maximum, 1440p, 150 кадров, VideoDepth + RAFT 10 + DLSS-G x2 | exit 0, 149 сгенерированных кадров, 49.94 FPS вывода, 0 underrun |
| Maximum, 1440p, без FG, 150 кадров | exit 0, 24.99 FPS вывода |
| Полный realtime-player, Medium, 1440p, локальный клип 9.6 сек, аудио включено (громкость 0) | Дошёл до конца, exit 0; slShutdown 0 |
| XAML и git diff --check | Пройдены |

Первые два native-теста используют один UHD-клип с позиции 120 секунд.
Параметры профилей считываются непосредственно из UI, а не подменяются Fast.
После исправления FG оба запуска содержат `slShutdown -> 0` и успешный
Feature 18 acceptance check.

Ограничения: это функциональные короткие тесты, не гарантия 90 FPS и не
длительный тест A/V-sync. Исходник 25 FPS с FG x2 даёт около 50 FPS, даже
при указанной цели 90. Maximum готовил guides около 10.3 FPS на ноутбуке;
короткий тест сглажен предварительным буфером. Для длительного просмотра
требуется дальнейшее ускорение или явный выбор пользователем более лёгких
настроек. На RTX 5080 выполнялись только чтение логов и проверка/перенос файлов,
без запуска видео, моделей или GPU-тестов.

Отдельно зафиксировано для дальнейшей работы: в тесте полного контроллера
с аудио FG дал только 12 дополнительных кадров из 240 исходных (в отличие
от прямых тестов renderer: 149 из 150). На конце короткого клипа контроллер
также перезапустил уже завершившийся аудиопроцесс. Исправление 22.0.1 не
объявляет эти отдельные проблемы FG/audio-clock решёнными.

Воспроизводимые тесты: `tests/test-depth-preflight.ps1` и
`tests/test-realtime-depth-profiles.ps1`. Локальные журналы данной проверки:
`temp/depth-v22-fix/` (не включаются в публичный репозиторий).
