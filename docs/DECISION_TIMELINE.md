# Decisions and measured results

[Demo guide](../DEMO_GUIDE.md) · [Architecture](../ENGINEERING_OVERVIEW.md) · [Full history](../ENGINEERING_HISTORY.md)

Each row links a public implementation change and the retained rationale/evidence. Commit dates are repository author dates, not a claim about commercial launch or external adoption. Historical results are not new measurements of the current checkout.

| Date / implementation | Problem → decision | Evidence and boundary |
|---|---|---|
| 2026-09-02 · [sample-clock audio](https://github.com/Absamad-dew/dlss5-video-studio/commit/2e5b174d4f36db2d96821a4e584d8491f819a72a) | Repeated endpoint restarts and noisy throughput samples destabilized audio → observe media/sample time and preserve the healthy endpoint through pause/resume | [Current source-linked explanation](../ENGINEERING_OVERVIEW.md#realtime-throughput-is-not-the-playback-clock). Playback timing is distinct from renderer throughput; no universal long-duration sync guarantee |
| 2026-09-03 · [NV12 transport and complete-frame buffering](https://github.com/Absamad-dew/dlss5-video-studio/commit/e35f5259564db3f9cbb7981476313e95cab42c43) | Fixed byte pipe was smaller than a high-resolution frame → preserve compact NV12, size the raw pipe in complete frames, bound in-flight chunks and retain periodic depth prefetch | [Contemporaneous README](https://github.com/Absamad-dew/dlss5-video-studio/blob/e35f5259564db3f9cbb7981476313e95cab42c43/README.md): 13.047→22.128 FPS native+NVENC transport comparison; distinct workload from V22 below. Do not add percentages across revisions |
| 2026-09-03 · [four-frame D3D12 pipeline](https://github.com/Absamad-dew/dlss5-video-studio/commit/384fb024fd43caf4a5709d42d5718727be74baf5) | Too little frame overlap → four complete frame slots matching twelve command allocators at three submissions per frame | [Contemporaneous note](https://github.com/Absamad-dew/dlss5-video-studio/blob/384fb024fd43caf4a5709d42d5718727be74baf5/README.md): three 120-frame A/B pairs, 1.23% median native gain, six byte-identical encoded files. A small measured gain, not a new application-wide multiplier |
| 2026-09-04 · [direct D3D12 NVENC](https://github.com/Absamad-dew/dlss5-video-studio/commit/10a1b267283299c388d2b7fd91bd09a837e40eb1) | Raw output readback and extra conversion/transfer limited delivery → GPU NV12 into NVENC, explicit resource fences and initialization-only fallback; correct fallback input color tags | [V22 original measurement](https://github.com/Absamad-dew/dlss5-video-studio/blob/10a1b267283299c388d2b7fd91bd09a837e40eb1/OPTIMIZATION_V22_RU.md): **24.393→29.981 FPS native-stage median (+22.9%)**. Native process including launch 7.745→6.963 s; separate complete recording 10.50 FPS. Decode/guides excluded from the A/B |
| 2026-09-04 · [dependency preflight and ordered shutdown](https://github.com/Absamad-dew/dlss5-video-studio/commit/d65c5e3186fc6be6ed10abcf8717cc0fce9c965b) | Missing Video Depth runtime failed too late; DLSS-G could crash after the last frame → validate dependencies before startup and stop Streamline workers before releasing tagged resources | [Reproduction and limits](../REALTIME_DEPTH_FIX_V22_0_1_RU.md). Correct process completion matters independently of displayed-frame count |
| 2026-09-04 · [stereo geometry preflight](https://github.com/Absamad-dew/dlss5-video-studio/commit/8140303cc92f96ca1fdb906872029d3a3d05d68c) | Forcing ultrawide source height could create an unsupported container → per-eye bounding boxes, layout/IPD-aware encoder guards, rejection before expensive work | [Worker](../python/iw3_worker.py), [existing CPU tests](../tests/test_iw3_worker.py), [runnable preflight](../scripts/demo-preflight.py). This is directly demonstrable without inference or a GPU |
| 2026-09-05 · [native VR and workspace update](https://github.com/Absamad-dew/dlss5-video-studio/commit/c7dea90d66a10448400920d1b29239d7c7db4da2) | Stereo reconstruction and large caches needed bounded execution; settings needed clearer separation → native streaming/repair work plus four UI workspaces and explicit presets | [VR QA](../NATIVE_VR_QA_RU.md) and [interface](../INTERFACE_RU.md). Short stage comparisons and the complete 4K-eye workflow have different boundaries; the latter is explicitly far from realtime |

The previous designs and observed failures remain in the [engineering history](../ENGINEERING_HISTORY.md). Neither this timeline nor the public demo substitutes synthetic preflight for a live native rendering run. No new output video, GPU measurement or quality ranking is introduced here.
