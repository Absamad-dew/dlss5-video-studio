# DA3 в IW3 / VR — Studio 22.2

Во вкладке **IW3 / VR → Модель глубины iw3** (список вверху блока) доступны
пять настоящих разных checkpoint. Выбор сохраняется в `settings/iw3.json`.

| Модель | Веса на диске | Назначение / ограничения |
|---|---:|---|
| DA3 Mono Large | 1.34 ГБ | Монокулярная глубина и небо; исходная DA3-модель iw3 |
| DA3 Small | 0.14 ГБ | Быстрые пробы; Studio-провайдер к iw3 |
| DA3 Base | 0.54 ГБ | Средний вариант, Studio-провайдер |
| DA3 Large **1.1** | 1.64 ГБ | Исправленные веса; тяжёлый вариант качества; CC-BY-NC |
| DA3 Giant **1.1** | 5.42 ГБ | Самый большой подключённый вариант; много VRAM; CC-BY-NC |

Это не переименование Small и не подмена весов при нехватке памяти.
Large/Giant 1.1 используются вместо устаревших исходных Large/Giant:
[авторы DA3 рекомендуют обновлённые checkpoint после исправления обучения](https://github.com/ByteDance-Seed/Depth-Anything-3#-model-cards).
Большая модель не гарантирует лучший силуэт, более стабильное движение или отсутствие
артефактов на конкретном фильме. Сначала сравнивайте короткий одинаковый отрезок.

## Установка и готовность

Выберите модель, нажмите **«Установить выбранную DA3»**. Над настройками показываются
описание, лицензия, размер, прогресс и скорость загрузки. Для Large/Giant интерфейс
попросит подтвердить некоммерческую лицензию. При остановке сохраняется `.partial`
для продолжения. Проверенный checkpoint публикуется только после SHA-256.
Существующие несовпадающие веса не перезаписываются.

Из PowerShell в папке программы:

```powershell
./scripts/Install-Iw3Da3.ps1 -Model Any_V3_Mono,Studio_DA3_Small,Studio_DA3_Base,Studio_DA3_Large_11,Studio_DA3_Giant_11
```

Для основы iw3 по-прежнему нужен `INSTALL_IW3.cmd`. DA3-установщик не меняет
Torch/CUDA и не устанавливает тяжёлые web/3D-reconstruction зависимости DA3.
Повторно используются совпадающие Small/Base в `models/depth`.
Исправленные Large/Giant лежат отдельно от старых моделей, не ломая прежние режимы.
В модели включены карточки лицензий; исходники и веса закреплены по commit/SHA-256
в `app/iw3-da3-models.json`. Весь каталог программы вместе с временными и скрытыми
файлами ограничен установщиком 50 **десятичными** ГБ, с резервом свободного места.

Проверка полного хеша выбранных весов и исходников, без GPU:

```powershell
./runtime/python/python.exe -s -B ./tools/iw3/iw3_da3_install.py --root . --models Studio_DA3_Large_11 --verify
```

## Настройка для 2–4K

- Кнопка **«Старт для кино: DA3 Mono / 518»** выбирает Mono, depth 518, microbatch 1,
  EMA и детекцию сцен. Она не меняет силу 3D, кодек или параметры заполнения.
- Для сравнения качества выберите Large 1.1 с теми же настройками. Giant 1.1 —
  дополнительный тяжёлый вариант; начните с depth 392/518, не сразу 1036.
- `Source` сохраняет размер исходного ракурса. Для Full SBS 4K получается
  7680×2160: нужен H.265. **Inpaint Max Width = 0** сохраняет RGB без уменьшения.
- Разрешение depth относится только ко входу нейросети: 518 → 756/1036 повышает
  стоимость и иногда детализацию границ, но не является апскейлом RGB.
- **DA3: кадров за один inference** — независимый microbatch 1–4. Он снижает
  пиковую память без пропуска кадров или замены модели. `Low VRAM` использует 1.
- **TTA** делает зеркальный проход последовательно, не удваивая пакет в VRAM.
  Он медленнее; качество необходимо сравнивать, а не считать автоматически лучшим.
- **Мягкость переднего плана** регулирует `1/(depth + shift)`, default 0.2 как
  в iw3 Mono. Общий параллакс задаётся Divergence, а не этим параметром.
- **Небо на дальнем плане** доступно только у Mono. Main-серия не выдаёт эту маску.
- **Depth AA** исходного iw3 не обучен для DA3 Main, поэтому недоступен там;
  у Mono доступен. EMA и сброс на склейках сохраняются у всех пяти вариантов.

## Что оптимизировано и чего здесь нет

Оригинальный nunif/iw3 не патчится: используется его публичный `depth_model` hook.
Mono работает с закреплённым [DA3-fork автора iw3](https://github.com/nagadomi/Depth-Anything-3_iw3),
Main — с закреплённой официальной DA3. Включены CUDA AMP/BF16 и PyTorch SDPA,
память весов загружается через mmap/assign без второй случайно инициализированной
CPU-копии. FP32 остаётся доступным для диагностики. INT8-квантизации нет.

Не загружаются camera/GS-ветки, не влияющие на depth без известных поз камер.
Это экономит память, особенно у Giant, но **не означает включение Gaussian Splatting**.
Здесь независимые покадровые предсказания DA3 + нормализация EMA от iw3, а не
официальный многокадровый DA3 Streaming. Смешивать кадры разных сцен как ракурсы
одной статичной сцены было бы некорректно, особенно с движущимися людьми.

Заполнение скрытых участков по-прежнему делает выбранный RowFlow/MLBW/Video Inpaint
iw3. Новая depth-модель сама по себе не дорисовывает скрытый фон. Опциональный
проход **DLSS 5 → iw3** и его настройки остались в блоке «Наши дополнения».
Настройки обычных RealTime/Record/VR-режимов не меняются.

## Проверки

`tests/test_iw3_da3.py` проверяет разные checkpoint, схему, готовность, алиасы общих
LayerNorm-параметров в safetensors и защиту
существующих файлов. `tests/test-iw3-ui.ps1` — пять вариантов, установку и доступность
только применимых параметров. `tests/smoke-iw3-da3.py` — opt-in NVIDIA-прогоны
всех пяти вариантов с оригинальным iw3 RowFlow (Inpaint задаётся через `--method`), полный decode, число кадров,
размер Full SBS и сохранение аудиопотока. Это функциональные проверки, не доказательство
превосходства картинки и не замер длительного FPS.

На ПК с 5080 выполняется только установка/проверка файлов; GPU-прогоны — на ноутбуке.

### Результат проверки 4 сентября 2026

На RTX 4060 Laptop (8 ГБ), в выделенных CoreBroker ресурсах:

| Проверка | Результат |
|---|---|
| Все пять DA3, 13 кадров 2560×1440 → Full SBS 5120×1440 | Успешно; полный decode, верное число кадров, аудиопоток сохранён |
| Mono в предыдущей строке | MLBW L2 Inpaint; остальные четыре — RowFlow v3 |
| Mono / Large 1.1 / Giant 1.1, 8 кадров нативного 2160×3840 → 4320×3840 | Успешно с RowFlow v3; полный decode, без уменьшения RGB |
| Обычный portable-запуск через process-iw3.ps1, Large 1.1 | H.265, 5120×1440, 13 кадров и исходный аудиопоток |
| DA3 Small: полный depth-путь и отключённые camera/GS-ветки | Побитовое совпадение результата на тестовом входе; microbatch-проверка также пройдена |

В этих коротких прогонах depth-вход был 518, у Giant — 392; TTA выключен.
Это проверки работоспособности, а не сравнительный тест качества моделей при одинаковых
настройках и не оценка скорости полнометражного видео. Сохранение аудиопотока не заменяет
длительную проверку синхронизации. Просмотр в VR-шлеме в эту проверку не входил.

**Полное 4K Inpaint на 8 ГБ не прошло проверку производительности:** отдельный прогон
Mono + Inpaint был остановлен при длительном упоре в память. Успешный 4K RowFlow
не означает, что 4K Inpaint так же лёгок. Настройки пользователя не понижались автоматически.

Все пять весов и закреплённые исходники установлены и проверены по SHA-256 на обоих ПК.
Каталог на E: ПК с 5080 занимает около 30.94 ГБ из разрешённых 50 ГБ; вычислительных
тестов на 5080 не запускали. После обновления нужно перезапустить программу.
